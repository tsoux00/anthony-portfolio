v1.1 · about

Release notes on how I work

I'm a Product Owner and Project Manager working across SaaS, mobile, and platform teams, translating strategy into a backlog that engineers can actually build from. My background moved through QA, full-stack development, and project management before product, so I read a sprint the way a tester reads an edge case — looking for what breaks.

I don't believe in roadmaps as decoration. Every item in mine has an owner, a reason, and a way to tell if it worked. I'd rather ship a narrow slice this sprint than a wide promise next quarter.

MINDSET

Decisions are cheap to reverse if you make them small. I optimize for reversibility, not certainty.

AGILE PHILOSOPHY

Scrum is a container, not a religion. I keep the ceremonies that create clarity and cut the ones that create theater.

PRODUCT VISION

A vision only counts if a new hire can repeat it back after one week. Anything longer than that is a slide, not a strategy.
